# practice-c

Just a repo for playing with C, while reading [Beej's Guide to C Programming](https://beej.us/guide/bgc/) to refresh my memory.

## Structure

- hello.c - my main working file up until i start to write multi-file code

## How to run

1. Install gcc/clang compiler
2. Run with `clang -Wall -Wextra -pedantic -std=c23 -o hello.out hello.c && ./hello.out` (C23 Standard with all diagnostic levels enabled)
